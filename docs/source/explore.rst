Explore a PIV field, live
=========================

A live, editable export of the `marimo <https://marimo.io>`_ notebook at
``docs/source/explore.py``, running entirely in your browser via
`Pyodide <https://pyodide.org>`_. Move the sliders and dropdowns and the
plot redraws immediately -- no install required. For a local session with
the full Python environment, download the file and run
``marimo edit explore.py`` (with pivpy installed).
